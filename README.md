# Переводчик учебного конфигурационного языка

Индивидуальная домашняя работа, вариант 16.
Лексический и синтаксический разбор выполняются инструментом SLY из лекции №3.

Нужен Python 3.11 или новее. Сборка не требуется.

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```
