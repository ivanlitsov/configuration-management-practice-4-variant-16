# Переводчик учебного конфигурационного языка

Индивидуальная домашняя работа, вариант 16. Программа читает конфигурацию
из стандартного ввода в UTF-8 и сохраняет JSON в файл. Лексический
и синтаксический разбор выполняет SLY.

## Установка и запуск

Нужен Python 3.11 или новее. Сборка не требуется.

```powershell
python -m pip install -r requirements.txt
.\run.bat test
New-Item -ItemType Directory -Force out
cmd /c "run.bat --output out\server.json < examples\server.cfg"
cmd /c "run.bat -o out\weather.json < examples\weather.cfg"
Get-Content -Encoding UTF8 out\server.json
Get-Content -Encoding UTF8 out\weather.json
```

Обязательный ключ `-o` или `--output` задаёт путь к выходному файлу.
Если разбор завершается с ошибкой, программа печатает сообщение в stderr
с номером строки и столбца, возвращает код 1 и сохраняет прежний файл.
Ключ `--help` выводит справку.

## Синтаксис

| Конструкция | Формат |
| --- | --- |
| Многострочный комментарий | `(* текст *)` |
| Целое число | `[+-]?\d+`, например `-15` или `+24` |
| Строка | `"Температура"`. Поддерживаются экранирования JSON |
| Массив | `array(1, "текст", {})`. Пустой массив — `array()` |
| Словарь | `{ port -> 8080. name -> "server". }`. Пустой словарь — `{}` |
| Имя | `[a-z]+` |
| Объявление константы | `let port = 8080;` |
| Использование константы | `@[port]` |

Документ содержит объявления констант, затем одно значение. Массивы и словари
могут содержать вложенные значения. Константа может содержать любое значение
и ссылаться на ранее объявленные константы. Повторное объявление константы
считается ошибкой. При повторе ключа словаря используется последнее значение.

## Примеры

- `examples/server.cfg` описывает порты и маршруты проверки HTTP-сервера.
  Получаются порты 8080 и 8443 и маршруты `/status` и `/ready`.
- `examples/weather.cfg` задаёт датчики и пороги метеостанции.
  В JSON сохраняются название «Север», поправки −2 и 0 и пороги −30 и 45.

## Функции модулей

- `lexer.py`: `ConfigLexer` распознаёт токены и пропускает пробелы и комментарии.
  `location()` вычисляет строку и столбец по позиции в исходном тексте.
- `parser.py`: `ConfigParser` описывает правила языка и вычисляет константы.
  `parse_config()` запускает лексический и синтаксический разбор и возвращает
  число, строку, список или словарь.
- `main.py`: `convert()` записывает результат разбора как JSON.
  `main()` разбирает аргументы, читает стандартный ввод и сообщает об ошибках.
